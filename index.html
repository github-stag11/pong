Space Pong

One arena. One side per player. Endless play.

Direct peer-to-peer connection — no game server. The host shares a code with each player by chat or e-mail.

Join a match

  1. Paste the offer code from the host
  2. Send this answer code back to the host

    2. Paste the answer code they return and press Connect.
